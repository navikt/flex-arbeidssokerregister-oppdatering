## Writing style

Write at about 80% of the way to ASD-STE100 Simplified Technical English.
Apply these rules to documentation, instructions and explanations.

- Use short sentences: about 20 words for steps, 25 for descriptions.
- Use active voice.
- Write one idea per sentence.
- Use simple, common words.
- Keep standard technical terms (for example Kafka, idempotent, transaction)
  as they are. Do not paraphrase them.
- Use one term for each concept. Do not use synonyms for the same thing.
- Use "must" and "do not" for requirements. Do not use "should", "may" or
  "could".
- Give steps in order. Write one action per step, in the imperative.
- When a step or rule needs judgment, add one short sentence that gives the
  reason.
- In explanations to the user, explain technical terms the first time they
  appear.
- In documentation, define project-specific terms in a glossary. Do not
  explain standard technical terms.
